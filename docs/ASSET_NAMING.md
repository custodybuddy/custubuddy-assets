# CustodyBuddy Asset Naming

Use lowercase kebab-case.

Pattern:

`cb-[asset-type]-[subject]-[context]-[orientation]-v##.[ext]`

Examples:
- `cb-illustration-evidence-files-office-portrait-v01.webp`
- `cb-template-instagram-carousel-hook-portrait-v01.webp`
- `cb-template-blog-featured-communication-landscape-v01.webp`
- `cb-background-legal-tech-grid-portrait-v01.webp`

## Asset types
- logo
- icon
- background
- texture
- illustration
- template
- product
- campaign
- audio
- reference

## Rules
- No spaces
- No dates in approved reusable filenames
- No tool-generated names such as "ChatGPT Image..."
- No `final`, `new`, `latest`, or `copy`
- Use version numbers instead: `v01`, `v02`
