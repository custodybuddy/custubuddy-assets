# CustodyBuddy Master Brand Asset Library

Central source of truth for approved CustodyBuddy visual, product, social, and campaign assets.

## Current structure

- `assets/brand/` — logos, icons, fonts, audio
- `assets/backgrounds/` — current legal-tech backgrounds and office scenes
- `assets/illustrations/` — reusable editorial illustration scenes by subject
- `assets/templates/` — reusable social and blog layout references
- `assets/campaigns/` — campaign-specific compositions
- `assets/product/` — product and website exports
- `assets/archive/` — superseded, celestial, and unclassified legacy files
- `docs/` — visual system, naming rules, and asset catalog

## Current visual direction

Use dark navy, cool blue haze, faint technology grids, and premium office scenes with deep navy drapes. Use celestial gold only as a restrained accent. Current production assets should not use star fields, orbital graphics, or gold background glow.

See `docs/STYLE_GUIDE.md` and `docs/ASSET_NAMING.md` before adding assets.
