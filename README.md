# CustodyBuddy assets

This repository contains approved visual, audio, font, and composition assets
for CustodyBuddy.

## Directory structure

- `assets/brand/` — shared identity assets, grouped by type: audio,
  backgrounds, fonts, icons, and logos.
- `assets/product/` — reusable product and marketing visuals.
- `assets/compositions/<composition-id>/` — media that belongs to one video
  or composition only.

## Naming rules

- Use lowercase kebab-case names that state the asset's purpose.
- Include a variant only when it clarifies use, such as `full` or
  `transparent`.
- Number ordered files with two digits, for example `slide-01-overview.png`.
- Do not use generic names (`hero.png`), dates, spaces, or `final` suffixes.
